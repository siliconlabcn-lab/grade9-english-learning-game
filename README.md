# 九年级英语 60→90 两个月提分计划

面向新人教版九年级、基础约 60/120 分学生的互动英语学习网站。目标是在八周内重点突破语法、词汇和阅读理解，建立冲刺 90 分的训练节奏。

## 功能

- 八周提分路线：每周五词汇语法、周六阅读攻坚、周日混合小测与错题复盘，共 24 次任务。
- 提分仪表盘：显示当前周次、完成次数、预计分数和 30 分目标拆解。
- 每日 15 分钟：作为轻量补充，10 题覆盖语法、完形填空、阅读理解、短文填空和词汇。
- 自适应难度：根据答题表现自动调整时间、提示、选项数量和重试机会。
- 课堂一对二 PK：单人挑战者对双人战队，支持计时、抢答、协作卡和教师控制。
- 词汇游戏：词义闪击、词形变身、拼写押分和错题复习。
- 本地进度：连续学习天数、星星、错题和掌握档位保存在浏览器中。

## 使用方式

网站为纯前端应用，不会上传学生姓名或答题记录。打开 GitHub Pages 链接即可使用。

## 本地预览

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。
